Journey Overview

一趟從平地慢慢走進楓紅深處的行程

前段在川越老街和果園裡放慢腳步，中段靠健走和三段不同的纜車爬上谷川岳、苗場高原， 順道繞去清津峽和赤城山，最後兩天回到東京，用庭園和市區血拼收尾。 體力最重的健走和纜車都排在中段狀態最好的時候，晚上都有溫泉可以泡，走起來會比較舒服。

Journey Highlights

整趟旅程最值得期待的畫面

四段不一樣的賞楓方式：用腳走、用纜車爬、用木棧道慢慢晃，體驗不會太單一。

🪨

一之倉澤健走

日本三大岩場之一，來回步行約2小時、路況平緩好走，近距離仰望巨大斷崖，配上秋天楓紅特別震撼。

🚡

谷川岳雙段纜車

廂型纜車轉乘吊椅式小纜車直上天神峠，360度俯瞰群山，山頂積雪、山腰楓紅、山腳新綠三層次同框。

🚠

苗場山龍纜車

日本最長的纜車，全長5.5公里、空中漫步約25分鐘，再串上田代纜車，居高臨下俯瞰二居湖與谷川岳。

🌈

清津峽光之隧道

日本三大峽谷之一，750公尺長的隧道藝術裝置，走到盡頭會利用水面倒影做出「天空之鏡」的效果。

🏔️

赤城山大沼・覺滿淵

火口湖畔的赤城神社紅橋配楓葉很好拍，加上有「小尾瀨」之稱的高山濕原木棧道，繞一圈約30-40分鐘，全家都能走。

🍎

原田農園採蘋果

群馬最大的觀光果園，10月正是蘋果產季，園內30分鐘吃到飽，離開前還能外帶兩顆走。

Day by Day

每日行程

左邊的顏色是體力節奏：綠色輕鬆、金色中等、紅色是這趟最操的健走日。

01

桃園機場 → 東京成田機場 → 成田飯店

🍳 早餐：不供應🍱 午餐：機上簡餐🍽️ 晚餐：飯店自助餐🏨 馬羅德國際飯店 或同級

中午搭乘國泰航空班機直飛成田，抵達後接往飯店，享用自助式晚餐，建議早點休息，為隔天的健走養精蓄銳。

02

飯店 → 小江戶川越老街 → 原田農園採蘋果 → 水上／苗場溫泉飯店

🍳 早餐：飯店內🍱 午餐：上州豚肉鍋定食＋蘋果汁🍽️ 晚餐：飯店百匯自助餐🏨 苗場王子大飯店 或 源泉湯の宿 松乃井

上午先到川越老街，走在保留江戶時期藏造建築的黑瓦老街上感受「小江戶」風情；接著到群馬最大的觀光果園採蘋果，30分鐘吃到飽還能帶兩顆走。傍晚入住溫泉飯店，吃完自助餐後好好泡個湯，把白天的疲勞卸下來。

03

飯店 → 一之倉澤健走 → 谷川岳雙段纜車＋彩虹散步道 → 越後湯澤溫泉飯店

🍳 早餐：飯店內🍱 午餐：日式料理🍽️ 晚餐：飯店自助餐🏨 (四星) Naspa 新大谷飯店

上午健走前往一之倉澤，來回約2小時、路況平緩，近距離仰望與劍岳、穗高岳齊名的巨大岩壁，秋天楓紅襯著絕壁格外好看。下午改搭纜車，先到天神平站再轉乘吊椅式小纜車上天神峠站，360度飽覽群山楓葉，最後沿彩虹散步道走回纜車站。晚上入住湯澤溫泉飯店，客房約37平方公尺，室內外溫泉開放到晚上10點。

04

飯店 → 苗場山龍纜車＋田代纜車 → 清津峽 → 清酒博物館・雁木通 → 越後湯澤溫泉飯店（傳統技藝＋抽獎晚會）

🍳 早餐：飯店內🍱 午餐：苗場烤雞腿排＋自助吧🍽️ 晚餐：飯店會席料理🏨 (四星) Naspa 新大谷飯店

這天的重頭戲是兩段纜車：日本最長的苗場山龍纜車（5.5公里、25分鐘）連接苗場與田代高原，中途再轉乘田代纜車，居高臨下俯瞰二居湖與谷川岳。接著到清津峽，走進750公尺長的「光之隧道」藝術裝置，隧道盡頭的水鏡效果能同時映出峽谷與天空。回程可以到清酒博物館或雁木通商店街走走（品酒、購物需自費）。晚上續住湯澤溫泉飯店，吃會席料理、看傳統技藝表演，還有抽獎同樂晚會。

05

飯店 → 赤城山大沼・赤城神社 → 覺滿淵自然遊步道 → 小沼展望地 → 免稅店 → 東京市區飯店

🍳 早餐：飯店內🍱 午餐：福豚之里涮涮鍋🍽️ 晚餐：敬請自理🏨 (四星) 東京巨蛋大飯店

上午到赤城山的火口湖「大沼」，湖畔赤城神社的朱紅神橋配上滿山楓葉很好拍照。接著走一段「覺滿淵」木棧道，這裡是海拔約1,360公尺的高山濕原，有「小尾瀨」之稱，繞一圈約30-40分鐘，老少都能輕鬆走完。之後到小沼展望地，天氣好時甚至能遠眺富士山。晚上入住東京市區飯店，附近有百貨和餐廳，晚餐可以自由選擇喜歡的東西吃。

06

飯店 → 小石川後樂園 → 東京成田機場 → 台北（桃園）機場

🍳 早餐：飯店內🍱 午餐：機上套餐🍽️ 晚餐：溫暖的家🏨 溫暖的家

早上到小石川後樂園走走，這是東京現存最古老的庭園之一，園內圓月橋的水中倒影會合成一個圓形，是熱門拍照點，秋天楓葉也很有看頭（也可以選擇睡晚一點、飯店自由活動，等集合時間再出發）。中午搭車前往成田機場，下午班機直飛回桃園，結束六天的賞楓健走行程。

  • 小孩不佔床（2～未滿12歲）扣 NT$4,000

  • 來回經濟艙機票、機場稅、燃油附加費

Good to Know

貼心提醒

  • 🛂護照效期需從回國日算起還有 6 個月以上，出發前請確認清楚。
  • 👥此團規定年滿70歲以上，若無同行家人或朋友，無法單獨報名參團。
  • 🔗行程為團進團出，中途無法脫隊、不可延回或退票。
  • 🍁楓葉轉紅速度會因氣候而提前或延後，若當年未轉紅，仍會依原行程前往景點遊覽。
  • 🚌依日本法規，遊覽車司機每日行車時間不得超過10小時，行程時間會以此為準安排。
  • 🛏️團體房型無法指定大床或加床，若飯店無法提供三人房，會改以雙人房加單人房安排。
  • 🥗日式素食習慣與台灣不同（常見蔥薑蒜蛋奶），素食旅客建議自備即食食品備用。
